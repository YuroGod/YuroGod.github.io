Native 层逻辑也很清晰：先校验 name 长度（6~20），再根据 name 生成 20 字节 hash，接着 Base64 解码 code，要求解码后长度必须为 20。

两边都拆成 5 个 DWORD，hash 会先做有符号整除 10。由于 Python 与 C 在整除行为上存在差异，写脚本时需要特殊处理

最后解一组简单的线性方程即可

java层的RSA用的是公钥解密 M=Ce mod nM=C^e\bmod nM=Cemodn

那么加密回去则需要用私钥 C=Md mod nC=M^d\bmod nC=Mdmodn

但公钥中只有 nnn 和 eee

import base64
import binascii
import hashlib

from Crypto.Cipher import AES, DES
from Crypto.Util.number import inverse

device_id = b"5dad0d73-5727-f5ba-a3ac-213fa9e2c00c"

sha1_data = hashlib.sha1(device_id + b"\x00").digest()

aes_key = sha1_data[4:20]
aes_data = AES.new(aes_key,AES.MODE_ECB).decrypt(sha1_data[:16])

crc = binascii.crc32(device_id) & 0xFFFFFFFF
crc_bytes = crc.to_bytes(4, "little")

des_key = bytes.fromhex("3F5D2313") + crc_bytes
des_data = DES.new(des_key,DES.MODE_ECB).encrypt(aes_data)

code_data = des_data + crc_bytes

# RSA
p = 298189805342220294696804713023137542429
q = 309795605909672789868308887071174440003

n = p * q
e = 65537
phi = (p - 1) * (q - 1)
d = inverse(e, phi)

# 00 14 | 20 bytes code | 10 bytes padding
block = b"\x00\x14" + code_data + b"\x00" * 10

m = int.from_bytes(block, "big")
c = pow(m, d, n)

code = base64.b64encode(c.to_bytes(32, "big")).decode()
